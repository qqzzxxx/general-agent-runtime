      Errors and warnings

        Human control

        Controls call the v1.2 Runtime entry points only. A mutation is never invented here and never edits authoritative Runtime files directly; the Runtime decides and reports the outcome.

        Safe Pause / Resume

        Resume clears the pause. The Runtime returns to RUNNING and the Orchestrator may start the next Supervisor turn. A HUMAN_REVIEW is not cleared by Resume — it needs a Human Decision below.

        Human intervention

        The intervention is queued for the next Supervisor turn (queued → delivered → consumed). Default: the current valid task may finish first.

        HUMAN_REVIEW — human decision required

        View Full Reason

        Data and history are preserved. The Runtime does not resume automatically from HUMAN_REVIEW; a Human Decision you submit below is required before the Supervisor can continue. Resume alone will not clear this state.

        Applying the decision transitions HUMAN_REVIEW → SUPERVISOR_TURN through the audited Runtime helper. It is bound to the exact state hash captured at prepare time; a stale or duplicated application fails closed and changes nothing.

        Interrupt current task

        Revokes the current task's Runtime authority using the existing fencing (the task is retired and quarantined), preserves all historical records, and leaves the Runtime paused; future work requires fresh authorization. This is cooperative — it does not kill the Executor process, which stops at its next control boundary.

        The current task will be retired (authority revoked), the TO_ZCODE dispatch quarantined, and the Runtime paused. History is preserved. Resume when you are ready.

        Formal STOP

        STOP is terminal and different from Pause: the Orchestrator makes no new Codex calls after detecting it, and an ordinary Resume will not resurrect the stopped work — recovery needs the documented STOP path. The Console asks the Runtime's formal STOP entry point to apply it after a confirmation challenge you request here.

        Artifact Center

        Read-only artifact workspace. Artifacts are discovered only from the active project's authorized publication roots (workspace/, evidence/, reports/) and the authoritative completion ledger.
